# Ronda 5 — Jeremias Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add 7 new characters (Jeremias, Baruque, Joaquim, Sedequias, Godolias, Ebede-Meleque, Nabucodonosor) to "Os Personagens da Bíblia", each with full content and a unique hand-drawn SVG portrait.

**Architecture:** No structural changes. Same `data/personagens.json` schema, same `app.js` engine, same `assets/retratos/<id>.svg` portrait convention established in Rounds 2-4.

**Tech Stack:** Static HTML/CSS/JS, hand-authored SVG.

**Spec:** `docs/superpowers/specs/2026-08-18-jeremias-design.md`

## Global Constraints

- Portrait SVGs: `viewBox="0 0 100 100"`, layer order clothing-band → neck rect → face ellipse → ears → hair/veil/beard → eyebrows → eyes → nose → mouth.
- Palette: warm tones only — browns, terracottas, ochres, olives, cream. No blue, violet, or teal.
- Every new portrait must be genuinely unique — no palette-swap of an existing portrait's shapes. Explicitly cross-check against the named comparison characters in the spec's casting section, not just within this batch. Also cross-check the 7 new portraits against each other.
- `data/personagens.json` field order per character: `id, nome, tipo, retrato, tier, x, y, era, refs` then `resumo, contexto, relacoes` on following lines — match the existing file's formatting exactly.
- `layout.width` changes from `3050` to `3300`. `index.html`'s `<svg id="graph" ...>` `viewBox` must change from `0 0 3050 820` to `0 0 3300 820` in the same commit — these two values must always match (this was a bug source in Round 1, caught again in every round's review since).
- No quizzes/gamification — this project is free-exploration content only.
- Ebede-Meleque's portrait must be a respectful, non-caricatured depiction of a Cushite (Nubian/Ethiopian) courtier — skin tone and hair texture consistent with that origin, no exaggerated features.
