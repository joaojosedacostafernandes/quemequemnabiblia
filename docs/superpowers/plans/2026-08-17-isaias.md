# Ronda 4 — Isaías Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add 4 new characters (Isaías, Acaz, Uzias, Senaqueribe) to "Os Personagens da Bíblia", each with full content and a unique hand-drawn SVG portrait, plus two small data fixes that connect this new block to the existing Ezequias character.

**Architecture:** No structural changes. Same `data/personagens.json` schema, same `app.js` engine, same `assets/retratos/<id>.svg` portrait convention established in Rounds 2-3.

**Tech Stack:** Static HTML/CSS/JS, hand-authored SVG.

**Spec:** `docs/superpowers/specs/2026-08-17-isaias-design.md`

## Global Constraints

- Portrait SVGs: `viewBox="0 0 100 100"`, layer order clothing-band → neck rect → face ellipse → ears → hair/veil/beard → eyebrows → eyes → nose → mouth.
- Palette: warm tones only — browns, terracottas, ochres, olives, cream. No blue, violet, or teal.
- Every new portrait must be genuinely unique — no palette-swap of an existing portrait's shapes. Explicitly cross-check against the named comparison characters below (same tier/role, most likely to collide), not just within this batch.
- `data/personagens.json` field order per character: `id, nome, tipo, retrato, tier, x, y, era, refs` then `resumo, contexto, relacoes` on following lines — match the existing file's formatting exactly (see any existing entry for the pattern).
- `layout.width` changes from `2900` to `3050`. `index.html`'s `<svg id="graph" ...>` `viewBox` must change from `0 0 2900 820` to `0 0 3050 820` in the same commit — these two values must always match (this was a bug source in Round 1).
- No quizzes/gamification — this project is free-exploration content only.
